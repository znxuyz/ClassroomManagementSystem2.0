# 功能介紹影片

一支約四分鐘的 mp4,從頭到尾用**真的程式**錄出來的 —— 畫面上每一個反應
都是系統自己跑出來的,不是動畫、不是截圖拼接。

```
bash tools/demo-video/build-all.sh            # 全部重跑(約六分鐘)
```

產出會放在 `/tmp/demo`(或第一個參數指定的資料夾):

| 檔案 | 內容 |
|---|---|
| `守護獸學園-功能介紹.mp4` | 成品(1280×720、25fps、含配樂與燒好的字幕) |
| `守護獸學園-功能介紹.srt` | 完整字幕,要上傳到影音平台或翻譯時用 |
| `bgm.wav` | 合成出來的配樂 |

## 為什麼是這樣做的

**用真的程式錄。** 示範影片最容易出問題的地方是「影片裡做得到,實際上做不到」。
這裡用 `tests/lib.mjs` 的假雲端 + 一份像真班級的 fixture 開一個完整的班,
再用 Playwright 一步一步操作它 —— 錄到的就是現在這一版真正的行為。
功能改了,重跑一次就有新的影片。(也因此它不會動到正在上課的那個 Firestore。)

**分兩段錄。** 老師端是電腦(1280×720),學生端是手機(390×844)。
學生端錄完之後放進畫面中央的手機外框裡 —— 老師要看懂「我發出去之後,
孩子那一邊長什麼樣子」。

**字幕兩種做法。** 老師端那一段直接燒在頁面上(`overlay.js`);
學生端那一段的畫面只有 390 寬,一行中文會排成四行蓋掉半個螢幕,
所以改成錄的時候只記時間,最後在 1280 的成品上用字幕檔燒。

**有假游標。** Playwright 錄下來的影片裡沒有滑鼠。少了它,觀眾會看到
「東西自己動」,不知道是誰按的 —— 而示範影片最重要的就是
「我按了這裡,所以發生那件事」。

**配樂是自己合成的**(`music.py`,numpy 寫的):授權乾淨,長度剛好配合影片。
沒有鼓、只用五聲音階、音量壓在 -25 dBFS —— 這是操作示範,
節奏感太強會搶走注意力。

## 檔案

```
record.mjs          錄影主程式(part = teacher | student)
scenes-teacher.mjs  老師端的分鏡
scenes-student.mjs  學生端的分鏡
overlay.js          字幕、章節標籤、標題卡、假游標(只在錄影時注入)
fixture.js          錄影用的班級資料(28 位、像真的一班)
music.py            配樂
build.sh            合成(接起來、配樂、輸出字幕)
build-all.sh        錄影 + 合成一次做完
```

## 改分鏡

`scenes-*.mjs` 裡一個場景就是一段:

```js
{ chapter: '班級管理', async run({ cap, click, point, go, sleep }) {
  await cap('點一位學生,右邊就出現他的守護獸和加分面板');
  await click('.student-item:nth-child(2)');
  await sleep(2200);
} }
```

* `cap(文字)` 換一句字幕(換的同時會把上一句的結束時間記進 srt)
* `click(選擇器)` 游標移過去、閃一下、再真的按下去
* `point(選擇器)` 只把游標移過去(用來「指著某個東西講」)
* `go(分類, 畫面, 子分頁)` 換頁
