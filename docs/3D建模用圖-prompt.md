# 給 image-to-3D 用的「乾淨版」守護獸圖

現有的 `assets/pets/*.png` 是**成品插畫**:有星芒、光暈、漂浮的粒子、戲劇性的逆光。
那些拿去餵 Tripo / Meshy 這類 image-to-3D 的工具,**特效會一起被做成實體幾何** ——
星芒變成尖刺、能量球變成一顆球黏在旁邊、漩渦變成繞著身體的帶子。
(實測過:5715 面裡有一大半是特效。)

所以建模要另外生一套圖。這一份放的是那套圖的 prompt。

## 一張能用的建模圖長什麼樣

| 要 | 不要 |
|---|---|
| 純白背景 | 任何背景元素、地面、陰影投射 |
| 平均的打光(像證件照) | 逆光、輪廓光、強陰影、夜景 |
| A-pose:手往兩側斜下、手掌打開 | 舉手、交疊、手擋住身體、握東西 |
| 全身入鏡,四肢都看得到 | 裁切、半身、透視壓縮 |
| 乾淨的色塊、看得出材質分界 | 星芒、光粒、煙霧、能量、發光特效 |
| 正面 / 側面 / 背面各一張 | 只有一張斜角 |

多視角輸入的結果明顯比單張好 —— 側面那一張決定了鼻子多長、肚子多厚,
只給正面的話模型會自己亂猜。

## 台灣黑熊・守護神獸

### 共用的角色描述(三張都用同一段,只換視角那一句)

```
Q版吉祥物風格的台灣黑熊幼獸角色,直立站姿,三頭身比例,大圓頭、大圓耳朵。
毛色是帶冷調的深黑色。胸前有一道奶油白的 V 形毛(台灣黑熊的特徵),
口鼻部是奶油白的短吻,鼻頭深褐色,兩道眉毛上方各有一撇奶油白短毛。
大眼睛,亮藍色虹膜。腳掌肉球是淺藍色。
身上穿戴金色的護具:兩隻手腕各一只金環、兩隻腳踝各一只金環、胸前一顆圓形金框藍寶石。
額頭正中央有一個金色的月牙形紋章(扁平的紋樣,不發光)。

畫法:乾淨的賽璐璐上色,色塊分明,沒有筆觸質感。
打光是平均的棚拍光,沒有方向性陰影,沒有輪廓光。
純白色背景。全身入鏡,頭頂和腳底都不要碰到畫面邊緣。
A-pose:雙手自然往兩側斜下張開約 45 度,手掌打開、五指分開,手上沒有拿任何東西。
雙腳與肩同寬站直。
```

### 設定上的提醒

- 如果你的生成工具支援**以圖生圖 / 參考圖**,把 `assets/pets/bear-guardian.png` 當參考,
  強度調低(0.3～0.45)。太高的話特效會跟著回來,太低的話就不像同一隻了。
- 三張要是**同一次 seed 系列**或用同一張參考圖,不然三視角會對不起來
  (側面的耳朵大小和正面不一樣,模型就會歪)。
- 原本那張插畫手上有一顆藍色能量球 —— 建模圖**不要畫**。
  球之後在 Blender 裡當獨立物件加上去,這樣才能讓它自己轉、自己發光,
  而且不會跟手掌黏成一塊。
- 同理,原插畫的肩甲尖刺如果太細,也建議簡化成圓角 —— 細尖刺在低面數模型上
  會變成破面。

## 用哪一個工具生

repo 裡**沒有留下記錄** —— README 和 `assets/pets/README.md` 都只講檔名,
沒寫是在哪裡生的,PNG 的 metadata 也被去背和縮圖那一步洗掉了。
現有的圖是 512×512 的 RGBA,邊緣有抗鋸齒,所以是**好好去過背**的(不是去背工具硬摳的)。

要補生新的圖,挑工具的重點不是畫質,是**能不能吃參考圖** ——
新圖得和現有那 32 張看起來是同一個世界的東西,不能只是「也很可愛」。

- **Google AI Studio 的畫圖模型**(Gemini / Nano Banana 那一系):免費,
  而且**你已經有 Gemini 的 API 金鑰**(系統設定裡那把)。它很擅長
  「保持這個角色,換一個姿勢」,正好是這裡要的事。
  做法:上傳 `assets/pets/bear-guardian.png` 當參考,再貼下面的 prompt。
- 其他吃參考圖的也可以(ChatGPT 的畫圖、Firefly…)。
  不吃參考圖的工具不要用在這件事上 —— 八隻會變成八種畫風。

> 這一次**把你用的工具寫在這一行**,下次就不用再猜了:
> 　生成工具:__________(日期:________)

## 其他七隻

把上面那段共用描述的**動物特徵**換掉就好,金色護具、月牙紋章、A-pose、
打光與背景那幾句原樣保留 —— 八隻共用同一套裝備規格,放在一起才像同一個世界的神獸。

| 動物 | 要換掉的特徵描述 |
|---|---|
| 石虎 | 黃褐色短毛,身上有深色斑點與條紋,臉頰兩側白色,耳朵背面黑底白斑 |
| 台灣藍鵲 | 寶藍色羽毛,紅色鳥喙與紅色腳,長尾羽末端白色,頭頸黑色 |
| 山羌 | 紅棕色短毛,體型小,額頭有深色 V 形紋,公的有一對短直角,尾巴內側白色 |
| 穿山甲 | 褐色鱗片覆蓋背部與尾巴,腹部是淺色軟毛,長吻,前爪大 |
| 台灣獼猴 | 灰褐色毛,臉部與臀部是粉紅色,尾巴中等長度 |
| 櫻花鉤吻鮭 | 銀藍色魚身,體側一排橢圓形暗斑,魚鰭半透明(直立擬人化) |
| 帝雉 | 深藍黑色羽毛帶金屬光澤,尾羽有白色橫紋,臉部紅色肉垂 |

四個階段(靈卵 / 幼獸 / 成獸 / 守護神獸)的差別建議這樣拉:

- **靈卵**:蛋,不用建人形,蛋殼上有那隻動物的花紋
- **幼獸**:同一隻但更圓、頭更大(二點五頭身),**沒有**金色護具,沒有月牙
- **成獸**:體型拉長一點(三點五頭身),只有手腕的金環
- **守護神獸**:完整裝備(手腕 + 腳踝 + 胸前寶石 + 額頭月牙)

這樣四階段是**同一隻在長大**,不是四隻不同的動物 —— 孩子才會有養大的感覺。
